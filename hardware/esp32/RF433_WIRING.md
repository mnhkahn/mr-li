# 这块 S3 的逐线接法

固件固定配置：**TX GPIO21，RX GPIO47**。依据 `../xiaoli/docs/flash-guide.md` 和
`../xiaoli/xiaozhi-esp32/main/boards/bread-compact-wifi-s3cam/config.h`：旧相机用了
GPIO4/5；21/47 分别是旧屏幕 RST/DC。独立固件没有屏幕、相机和音频驱动。
如果排针 21/47 还连着屏幕跳线，先将这两根屏幕线拔掉。这里“21/47”指 GPIO
丝印编号，不是数排针的第 21/47 根。

先断开供电接线。模块针脚必须看实物丝印 DATA/VCC/GND，不按商品图左右顺序猜。
商品图接收板两端的“5V电源”没有区分正负；发射板 DATA 被误标成“输出”。

## 只有模块和杜邦线时：低压试验接法

用户当前没有电平转换器。先断开 USB，再只接接收板进行试验：

| 接收板 | ESP32 |
|---|---|
| VCC | **3V3** |
| GND | GND |
| DATA | GPIO47 |

这块接收器的商品额定供电是5V，3.3V属于额定外的低压尝试，不保证能工作或达到
正常灵敏度。使用3.3V供电是为了先避免5V输出直入GPIO；如果收不到，不能据此判断
固件或遥控器损坏，也不能在DATA仍直连时改回5V。届时应恢复下方额定供电/电平适配方案。

学习成功后再接发射板：VCC→5V，GND→GND，DATA→GPIO21，先验证3.3V GPIO直驱。
FS1000A采用5V供电、DATA直连3.3V GPIO有公开应用先例，但不同批次仍需实测；
若驱动不足再加缓冲器。两块各接约17.3cm直线天线。固件引脚配置不变。

参考：[Kontron PiXtend硬件手册，433MHz发射器章节](https://www.kontron-electronics.hu/fileadmin/media/downloads/handbuecher_dokumentationen/raspberrypi/PiXtend_V2-S-Hardware_Manual_EN.pdf)。

下面保留的是按额定5V工作的电平适配接法，不代表用户当前已拥有这些器件。

## 共用电源

| 从 | 到 |
|---|---|
| ESP32 板的 5V/VBUS | 接收模块 VCC、发射模块 VCC、74AHCT125 VCC |
| ESP32 板的 3V3 | 74LVC1G17 VCC |
| ESP32 板的 GND | 两块 RF 模块 GND、两颗缓冲器 GND |

使用当前 USB 给开发板供电。只有确认丝印为 5V/VBUS 的脚才能作为 5V 分配点，
不是 EN、VIN 未知或 GPIO。接收器按资料使用 5V，不能直接把它的 DATA 当作 3.3V。

## 发射模块

选择 **74AHCT125** 的一个非反相缓冲通道（注意 AHCT，不是仅写 HC 的器件）：

| 连线 | 说明 |
|---|---|
| GPIO21 → AHCT125 的 1A | 3.3V 输入 |
| AHCT125 的 1Y → 发射板 DATA | 5V 基带输出 |
| AHCT125 的 /1OE → GND | 使能这个通道 |
| 1A → 10kΩ → GND | 上电和复位时保持发射关闭 |
| 发射板 ANT → 约17.3cm导线 | 天线，初测尽量伸直 |

**仅对标准 DIP-14/SOIC-14 引脚布局**：1脚=/1OE，2脚=1A，3脚=1Y，7脚=GND，
14脚=VCC。其他封装/成品模块请按自身 A/Y/OE/VCC/GND 标注，不套用这个脚号。
未用通道的输入固定到 GND，未用通道 /OE 接 VCC，输出不接。

## 接收模块

使用 **SN74LVC1G17**（5V 容限输入、3.3V 供电、施密特非反相输出）：

| 连线 | 说明 |
|---|---|
| 接收板 DATA → LVC1G17 的 A | 接收器信号输入缓冲器 |
| LVC1G17 的 Y → GPIO47 | 3.3V 信号进入 ESP32 |
| LVC1G17 VCC → 3V3 | 不能在这里接 5V，否则输出也会变成 5V逻辑 |
| 接收板 ANT → 约17.3cm导线 | 接收天线 |

接收板若有两个 DATA，确认它们确实同网后只用一个，另一个悬空；不能把 DATA 当
作第二个 VCC。建议使用已焊的缓冲器转接板。电阻分压需要核实接收 DATA 的真实
高电平及 GPIO 输入门限，不能仅按模块供电 5V 推算；本接线表采用缓冲器方案。

每块模块及缓冲器供电附近放 100nF 去耦，5V 分配处加 10–47µF 电容。RF 接收板
尽量离开 ESP32 天线和电源线；发射学习分时工作。

## 接好后的操作

1. HA 的“窗帘射频控制器”应显示 TX=21、RX=47，发射开关保持关闭。
2. 点击“窗帘学习上升（三次短按）”，在 30 秒内对着接收板短按原遥控器上升键
   三次，每次松开至少 1 秒。看 matches/bursts 进度，完成后 learned.up 应大于0。
3. 分别学习下降、停止。每次学习会先关闭发射；单次长按不当成三次独立按键。
4. 核对三种码确实是各自按键的稳定固定帧，再打开“窗帘确认固定码并启用发射”。
   不同动作学成同一码会被拒绝。
5. 先验证停止，再短时升、降并停止。没有动作反馈，不显示真实开合百分比。

学习超时并不说明固件坏了：查接线、电平、天线、接收频点、帧间隙和实际协议。
如果是滚动码/不兼容调制，这版原始固定码学习不会自动解决协议问题。
