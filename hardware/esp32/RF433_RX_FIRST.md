# 按 IMG_5305 先接收端：最少改动

当前先测试接收，发射板暂不接。麦克风及其GPIO1/2/42、电源、地线保持不动。
照片中两端插牢、没有碰线的旧短跳线可以暂留，无需清空整个面包板。

先拔USB，把接收模块放到左边面包板空白的a–e区域。若是4针接收板，四根针应
分别占用四个不同编号行，例如c20、c21、c22、c23；不能横插进同一行a20～e20，
同组五孔内部连通，会把电源和信号短接。主板左侧插脚所在f–j组不要占用。

按接收板实物丝印认VCC/GND/DATA，以上示例不代表四根针的功能排列顺序。

| 接收板 | 当前线路 |
|---|---|
| VCC | 右侧红色＋轨，已有长橙线从主板3V3供电 |
| GND | 已与主板GND相连的右侧蓝色－轨 |
| DATA | 右侧面包板g26等空孔；第26行灰桥接主板GPIO47，灰桥保留 |

若接收板有两根DATA，只有确认它们为并联DATA后，选一根连接，另一根不接。
无清楚丝印时应先看模块正反面，不能根据商品图左右顺序猜。
ANT接约17.3cm单根导线，另一端悬空。GPIO21和发射板本阶段均不用接。

接收模块标称5V供电。这里仅用3.3V作无转换器的低压试验，可能收不到信号或
灵敏度不足。不能在DATA直连GPIO47时把VCC改供5V；若低压不工作，应增加电平适配，
然后按额定供电方案接线，不将失败直接归因于软件。

接好并确认针脚后再插USB。由用户确认接线完成后，开启接收学习窗口，再按原
遥控器同一个正常按键三次，每次按约0.3秒、松开至少1秒，观察frames_seen/matches/
bursts。第一次只验证能否收到；不启用射频发射，也不操作遥控器配对/清码/行程键。
