# 按 IMG_5305 先接发射端：最少改动

用户已拆下紫色功放/喇叭，麦克风必须保留。本阶段只接FS1000A/MX-FS-03V发射板，
接收板暂不接。

## 旧线要不要拆

照片中的旧短跳线两端插牢、没有碰到别的引脚时，可以暂留。无需把面包板清空。
保持麦克风及其供电/信号线、公共地、上方长橙色3V3供电线不动。

用于复用的线可以整根拔下再接新用途；裸露悬空端要拔掉或收好。新模块若占用某行，
必须确认同组五孔里没有旧GPIO/电源线混接。避免这一步的最简单办法：把发射板放在
**左边面包板空白的a–e区域**，不占右侧旧功放的线路区，也不占左侧主控插脚所在f–j组。

## 只接三根线

先拔USB，按发射模块实物GND/VCC/DATA丝印认针，不按商品图左右顺序猜。

| 发射板 | ESP32/现有线路 |
|---|---|
| VCC | 主板左下标5V的针，同侧同排空孔可引出；不是GPIO5 |
| GND | 已与主板GND相连的右侧蓝色负电源轨，或主板任一GND |
| DATA | 右侧面包板第27行橙色短桥引出的GPIO21；保留短桥，从该行f–j空孔引出 |

发射板三根针要落在**三个不同编号行**的a–e孔组；不要横插在同一行a/b/c里，
那会使VCC、GND、DATA短接。也可使用三根独立母杜邦线，不必把发射板插上面包板。

目前右侧红色＋电源轨由主板3V3供电。发射板5V单独拉线，不接该红轨，
也不要把5V并到该轨，否则会与3.3V短接。移除的功放/屏幕线可按长度复用。

ANT另接约17.3cm单根导线，另一端悬空。它不接GPIO，也不接主控的金色天线座。
固件保持TX=21，RX=47；本阶段47不用接。GPIO3.3V直驱发射DATA为试验方案，
仍需验证具体模块是否可靠触发。

这一步只是完成发射硬件接线。未学习实际遥控码前，固件保持发射禁用；不发猜测码。
