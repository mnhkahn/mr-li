# 按当前实物照片复用旧接线（2026-11-22）

依据用户照片 IMG_5304.HEIC 和旧 S3CAM config.h。照片中的主板为
GOOUUU ESP32-S3-CAM V1.5；右上圆板是麦克风，紫板是 MAX98357A 功放，
镜头是摄像头。照片未展示屏幕本体或433MHz收发模块。

以下方向与照片一致：两个 USB 口朝下，右侧面包板的编号从上往下递增。
GPIO编号和面包板行号是两套数字，不要混淆。

## 保留与移除

先断开 USB 供电。

- 保留主板及其面包板安装位置，摄像头可以保留，当前固件不启用它。
- 移除屏幕外接线、紫色功放和喇叭线。**圆形麦克风及其全部现有线路保留**，
  用户后续还要使用麦克风；不得把麦克风的电源线或信号线拿去改作射频用途。
- 保留左上3V3到右侧红色正电源轨的长橙线。
- 保留主板GND到公共地轨的供电线；按板上GND标记核对，不能按橙/灰颜色猜电源极性。
- 保留右侧面包板第26、27行的灰/橙跨沟短桥，作为RF信号的引出。
- 只清理屏幕和功放专用支线，保留麦克风线路及公共供电、地线。拆下的屏幕/功放线
  可复用，不能把公共供电轨的馈线误当成功放专用线拔掉。

## 麦克风原样保留

旧 S3CAM 配置启用 AUDIO_I2S_METHOD_SIMPLEX，麦克风与功放使用不同的I2S信号线：

| 麦克风端 | 主控连接 | 本次处理 |
|---|---|---|
| VDD | 3V3（照片右侧现有3.3V红色＋轨） | 保留 |
| GND | 公共地 | 保留 |
| WS | GPIO1 | 保留 |
| SCK | GPIO2 | 保留 |
| SD | GPIO42（主控I2S输入） | 保留 |
| L/R | 原来的声道选择接法 | 不改 |

射频仍使用TX21/RX47，与麦克风GPIO1/2/42不冲突。功放的39/40/41为另一组信号，
不要把它们与麦克风线路混在一起。接收板的低压试验可共用现有3.3V和GND轨；
发射板5V必须独立引线，不能并入麦克风所在3.3V轨。

当前硬件控制固件没有运行I2S录音，保留线材不等于麦克风功能已经启用。
后续添加录音时沿用1/2/42，不需要恢复小智智能体，也不需要改动射频GPIO。

## 可复用线路

| 照片中的线路 | 已确认来源 | 改作 |
|---|---|---|
| 右侧第26行灰色短桥 | 主板G47/GPIO47 | 接收板DATA |
| 右侧第27行橙色短桥 | 主板G21/GPIO21 | 发射板DATA |
| 上方长橙线接入的右侧红色＋轨 | 主板左上3V3 | 接收板低压试验供电 |
| 已与主板GND相连的蓝色－轨 | 公共地 | 两块模块GND |
| 从拆下的线中取一根，重新接主板左下5V | 5V电源，非GPIO5 | 发射板VCC |

第26/27行的短桥分别把右侧面包板的 a–e 与 f–j 组接通。
因此保留短桥后，可在对应行 f–j 中的空孔（例如g26/g27，确认没有其他线占用）
引出数据线；也可以复用原先接屏幕DC/RST的长线，只更换屏幕端为接收/发射DATA。
以板上G47/G21丝印和实际导通关系为准，照片颜色只用于定位这张照片。

**当前右侧红色正电源轨是3.3V，不是5V。** 不要再把主板5V接入这条轨，
否则会把两路电源短接。发射板5V使用一根独立线，或另设明确分开的空闲5V轨。

## 仅有杜邦线时的一次接好表

这是与先前约定一致的低压试验方案，不代表接收板3.3V工作已被验证。

| 模块端 | 复用接到 |
|---|---|
| 接收板VCC | 右侧现有3.3V红色＋轨 |
| 接收板GND | 已确认与主板GND相连的公共地轨 |
| 接收板DATA | 右侧第26行 / GPIO47 |
| 发射板VCC | 主板左下5V，独立供电线 |
| 发射板GND | 同一公共地轨 |
| 发射板DATA | 右侧第27行 / GPIO21 |

接收板标称5V供电，3.3V低压尝试可能完全收不到或灵敏度不足。
如果收不到，不得在DATA仍直连GPIO47时把接收板VCC改供5V；应改用额定供电及
电平适配方案。发射板3.3V GPIO直驱也需实测，不保证所有同名板都适用。
额定供电方案见 [RF433_WIRING.md](RF433_WIRING.md)。

模块VCC、GND、DATA按各自实物丝印连接，不按商品图左右顺序猜。
面包板同一侧、同一编号行的5孔通常内部连通，模块各引脚必须落在不同电气节点，
不要把VCC/GND/DATA横着插进同一组5孔。不同板或不同电源轨不默认导通。

两块收发模块的ANT各接约17.3cm直线导线；ANT不是DATA。
它们通过GPIO连接ESP32，不插主板上的2.4GHz天线接口。

接好再供电，在HA“硬件控制→窗帘”分别学习升、降、停。保持现有TX21/RX47固件
配置；拆除屏幕、功放并保留麦克风不需要更换射频GPIO。当前尚无实物RF码学习或电机动作确认。
