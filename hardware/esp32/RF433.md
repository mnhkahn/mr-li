# 433 MHz 电动窗帘发射

本次设备信息：窗帘品牌 LONGSAM（朗森），手头发射模块 MX-FS-03V，
尚未连接。电机及遥控器的具体型号、三个按键编码仍待确认。

## 查到的资料

- LONGSAM 官方的 [LM25A 说明书](https://www.langsenjd.com/wp-content/uploads/2026/01/2026012802003733.pdf)
  标注无线频率为 **433.925 MHz**。这只证明该型号的频率，不能据此认定
  用户手里的所有 LONGSAM 电机都采用同一编码或固定码。
- 品牌官方也销售 Zigbee、Matter、Wi-Fi 等不同系列，部分系列同时带
  [433 MHz 遥控](https://www.langsenmotor.com/motor/curtain-motor/3-wire-zigbee-curtain-motor.html)。
  不能仅凭品牌猜测开、关、停的码值。
- [MX-FS-03V 模块资料](https://www.mantech.co.za/Datasheets/Products/MX-XXX-240417A.pdf)
  将其列为 433 MHz **AM 发射器**，不是接收器。因此它不能直接学习原遥控器。
- [rc-switch](https://github.com/sui77/rc-switch) 支持 PT2262、EV1527 等
  多种常用 AM 固定码，但不是所有窗帘遥控器的通用协议。
- [Somfy RTS 实现](https://github.com/Legion2/Somfy_Remote_Lib) 使用特定
  帧格式和滚动码存储，且工作于 433.42 MHz。这里没有把它当作 LONGSAM 协议。

结论：已准备通用的**固定码原始 OOK 波形发送**；尚不能声称已适配
用户这台 LONGSAM。须拿到具体遥控型号、可靠协议资料，或用接收模块/
逻辑分析方式采集真实的升、降、停波形，再确认多次发送的稳定性。
如果确认是滚动码，需要增加对应协议、遥控身份和计数器管理，不能重放旧码。

## 接线要求

MX-FS-03V 按实际丝印接 `DATA`、`VCC`、`GND`：

| 模块 | 连接 |
|---|---|
| GND | ESP32 GND，共地 |
| DATA | 配置的 ESP32 TX GPIO |
| VCC | 按手中模块资料供电；资料所列版本为 5 V |

同名模块资料可能不同，应核对手中板子的供电和 DATA 输入电平规格。
ESP32 GPIO 是 3.3 V 逻辑，不能把模块供电电压接到 GPIO；必要时加适当
电平转换。不要根据照片方向猜引脚顺序。天线与载波由模块决定，GPIO/RMT
仅提供基带高低电平，代码不能让 ESP32 自己产生 433 MHz 射频。

固件默认不配置、不驱动任何 RF GPIO。可配置引脚：C3 的 GPIO4..7/10，
S3 的 GPIO4..18/21。这些范围避开 USB、常见 flash 和启动配置引脚；
具体板子可能仍有其他外设占用，接线前需确认该板原理图。

## MCP 工具

- `self.curtain.status`：查看配置、忙碌状态、最近动作和错误。
- `self.curtain.configure`：保存 TX 引脚、重复次数、三个动作的真实波形；不会发射。
- `self.curtain.up`：升。
- `self.curtain.down`：降。
- `self.curtain.stop`：停止；发射期间优先在下一帧边界切换到停止码。

三种动作均接受 `{}`。首次先配置波形，以下只是结构模板，**空数组会被拒绝**：

```json
{
  "protocol": "raw_ook_fixed",
  "tx_gpio": 4,
  "repeat": 6,
  "up": [],
  "down": [],
  "stop": []
}
```

数组是微秒时长，必须从正数开始，按 `+高电平、-低电平` 交替，以负数结束。
包含同步头/尾和必要帧间空隙，不能只填十进制按键码。每个动作 2..128 个
时长，每个绝对值 1..32767 µs，一帧不超过 150 ms，重复 1..10 次。
这里的 1 MHz 是 RMT 定时分辨率，**不是射频频率**。

配置保存在独立 NVS 命名空间。发射使用硬件 RMT，避免软件延时被蓝牙任务
打断而影响码型。升/降发射期间不接受其他方向，但接受停止请求；正常情况
下一帧边界（单帧上限 150 ms）转发停止码。广播完成并不代表电机已停止或
到达某位置，返回 `physical_effect_confirmed: false`，需现场确认。

接收学习硬件、完整 LONGSAM 专用编码和真实电机动作尚未验证。不会仅因
软件测试通过就标记为兼容 LONGSAM。
